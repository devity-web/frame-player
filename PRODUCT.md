# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Paste a remote MKV URL, play the video, and switch among its audio tracks, including English and Portuguese.

## Capabilities and Constraints
Next.js and shadcn. The user requires serverless deployment with a Next.js Server Component page. Interactive playback runs in a Client Component. Browser decoding and remote CORS access constrain playable sources. No persistent video server.
